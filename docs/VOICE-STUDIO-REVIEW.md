# Voice Studio incelemesi — 20.10.2026

Kaynak: https://github.com/msrbuilds/voice-studio commit 4ffa945627dd599e308b7e6ef4e55fb172c6a09c, MIT. Kod incelendi; projenin sunucusu ve kurulum betikleri çalıştırılmadı. En uygun parça Kitten TTS Mini CPU motoru ve yayımlanan sekiz ses kimliği. Motor kodu KittenML resmi 0.8 wheel kaynağından Apache-2.0 kapsamında uyarlanmıştır; Voice Studio arayüzü kopyalanmadı.

Seçim: 80M ONNX Kitten Mini 0.8, yaklaşık 80 MB model ve 3,3 MB ses profilleri. Model revision ve SHA256 docs/voice-studio-model.json içinde. API anahtarı, GPU, Hugging Face hesabı veya çalışma sırasında indirme yok. Türkçe EMA korunur; İngilizce normal ders ve hazırlama yerel motora yönlenir. İlk açılışta ses için gereksiz API testleri kaldırılır. Kullanıcı açıkça bulut medya önizlemesini seçerse o ayrı servis kullanılabilir; isteğe bağlı öğretmen değerlendirmesi veya web araması çevrimdışı hale getirilmiş sayılmaz.

Voice Studio'daki daha büyük modeller: VibeVoice, Chatterbox, OmniVoice, VoxCPM2 ve Qwen3-TTS daha fazla disk/RAM/ortam gerektirdiği için eklenmedi. Whisper transkripsiyon ve M2M/Argos çeviri bu ses üretimi ihtiyacının kapsamına alınmadı. Kişisel ses kaydı veya klonlama eklenmedi. Segmentli anlatım ve ses arşivi zaten uygulamada vardır; İngilizce motor bunları kullanır. Hız değişikliği yeniden ses üretmez; yinelenen hazırlama çağrıları tek üretimi paylaşır; iptal edilen ses sonradan çalmaz.

Belge doğrulama: Context7 aramasında Voice Studio/Kitten için uygun indeks bulunamadı, resmi depo ve 0.8 wheel kaynakları okundu. ONNX Runtime CPUExecutionProvider/SessionOptions ve Phonemizer Windows EspeakWrapper.set_library belgeleri Context7 üzerinden doğrulandı. Runtime ONNX 1.25.0, phonemizer 3.3.0, espeakng-loader 0.2.4; tam bağımlılık kilidi voice-studio-runtime-lock.txt. Ağ bağlantıları yasaklanan işlemde sekiz sesin hepsi gerçek, sessiz olmayan WAV üretti. Taşınabilir Python kopyası kullanıldı. Windows yerel media_request köprüsü de gerçek WAV üretti. Fiziksel hoparlörden kalite dinleme ve temiz Windows sanal makinesi doğrulanmış değildir.
