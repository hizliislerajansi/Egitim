# Güvenlik

Güvenlik açığı bildirirken öğrenci verisi, erişim anahtarı, parola ve oturum dosyası paylaşmayın. Depoda özel güvenlik bildirimi etkinse GitHub'ın Security bölümünü kullanın; herkese açık kayıtlara gizli bilgi eklemeyin.

Güncelleme kaynağı yalnız yönetici panelinden değiştirilir. Kontrol herkese açık GitHub Releases verisini kullanır; hesap anahtarı göndermez. Uygulama uzaktan gelen HTML çalıştırmaz veya kurulum dosyasını kendiliğinden başlatmaz.

Güncellemeden önce öğrenci yedeği alın. Profil ve yerel model klasörlerini koruyun. Kurucunun yayımlanan SHA256 değerini karşılaştırın. SHA256 kontrolü yayıncının dijital imzasının yerine geçmez.
